Corporate Finance: Risk, Cost of Capital, Leverage & Dividend Policy

第13章：風險、資本成本與估值

本章核心：理解為什麼公司必須賺取的最低回報率取決於其風險程度。這是所有投資決策的基礎。

資本成本的基本原理
Cost of Capital - Fundamental Principle
💡 淺顯易懂的解釋
想像你有 $100,000。你可以：
選項A：自己投資一個公司項目
選項B：把錢投資到股票市場（風險相同）

如果股票市場每年給你 12% 的回報，那麼你的公司項目也應該至少賺取 12%，否則你會選擇股票。
這 12% 就是你的「資本成本」。
核心邏輯
  • 相同風險 = 相同的必要回報率
  • 股東可以在任何地方再投資股利
  • 公司必須提供至少相等的回報
CAPM 公式（計算股權成本）
Capital Asset Pricing Model (CAPM)
RE = RF + β × (RM - RF)
公式說明：
RE = 股權成本（股東要求的回報率）
RF = 無風險利率（通常用1年期國債）
β = 貝塔系數（衡量股票的波動性/風險）
(RM - RF) = 市場風險溢價（市場平均回報 - 無風險利率）
直觀理解
無風險利率：你投資最安全的資產能賺多少（比如國債）
風險溢價部分：因為股票有風險，所以要多付一點。付多少？看你的貝塔有多高。
最終的 RE：你投資這支股票應該要求的最低回報
實際例子
情景：計算蘋果公司的股權成本

已知數據：
• 無風險利率 RF = 2%
• 蘋果的貝塔 β = 1.2
• 市場風險溢價 = 8%

計算：
RE = 2% + 1.2 × 8%
RE = 2% + 9.6%
RE = 11.6%

含義：投資蘋果股票，你應該要求至少 11.6% 的年回報。
貝塔系數（β）詳解
Beta Coefficient - Systematic Risk
β = 股票波動性 / 市場波動性
淺顯解釋
貝塔衡量的是：當市場下跌 1%，你的股票通常下跌多少？

• β = 1：市場跌 10%，你的股票也跌 10%（同步）
• β = 1.5：市場跌 10%，你的股票跌 15%（更波動）
• β = 0.5：市場跌 10%，你的股票只跌 5%（更穩定）
貝塔的三大決定因素
  • 收入周期性：高科技、汽車行業 → 高貝塔；食品、日用品 → 低貝塔
  • 經營槓桿：固定成本多（如航空公司）→ 高貝塔；變動成本多 → 低貝塔
  • 財務槓桿：借錢越多（債務比高）→ 貝塔越高
行業比較
高貝塔公司（波動大）：
• 特斯拉（科技汽車）：β ≈ 2.0
• 美國航空（周期性強）：β ≈ 1.8

低貝塔公司（穩定）：
• 可口可樂（必需消費）：β ≈ 0.6
• 公用事業（穩定現金流）：β ≈ 0.8
加權平均資本成本（WACC）
Weighted Average Cost of Capital (WACC)
WACC = (E/(D+E)) × RE + (D/(D+E)) × RD × (1-TC)
每部分的含義：
E/(D+E) = 股權佔總資本的比例
D/(D+E) = 債務佔總資本的比例
RE = 股權成本（用CAPM算）
RD = 債務成本（借錢的利息率）
(1-TC) = 稅盾調整（利息可以抵稅）
核心意義
WACC = 公司用來融資的平均成本

簡單理解：如果一家公司 60% 用股權融資，40% 用債務融資，那麼總的融資成本就是這兩個成本的加權平均。

重要用途：WACC 是評估任何投資項目的貼現率。NPV > 0 的項目才值得做。
WACC 計算器
加權平均資本成本 (WACC)
—
實際計算案例
某公司數據：
• 股權市場價值：$60M
• 債務市場價值：$40M
• 股權成本：14.4%
• 債務成本：5%
• 稅率：34%

計算步驟：
權重：股權 = 60/100 = 60%，債務 = 40/100 = 40%
債務稅後成本 = 5% × (1-0.34) = 3.3%
WACC = 60% × 14.4% + 40% × 3.3%
WACC = 8.64% + 1.32% = 9.96%

含義：公司所有投資必須至少賺取 9.96% 才值得做。
股利貼現模型（DDM）
Dividend Discount Model (DDM)
P = Div / (RE - g) 其中：RE = Div/P + g
P = 股票價格（今天）
Div = 下一年的股利
RE = 股權成本（要求的回報率）
g = 股利永久增長率
直觀理解
股票值多少錢？它值它將來所有股利的現值之和。

簡化版：假設股利永遠按 g% 的速度增長，那麼：
股票價格 = 明年股利 ÷ (你要求的回報 - 增長率)

分母為什麼是「回報率 - 增長率」？因為增長率已經包含在股利的增長中，所以要扣掉。
股票估值例子
Microsoft 股票估值：
• 下一年預期股利：$1.05/股
• 股利增長率：g = 3%
• 要求的回報率：RE = 10%

計算：
P = $1.05 / (10% - 3%)
P = $1.05 / 7%
P = $15/股

含義：如果股票以 $15 或以下的價格賣，就值得買。

第18章：有杠杆公司的估值與資本預算編制

本章核心：當公司用債務融資時，如何評估投資項目？三種方法各有用途。

調整現值法（APV）
Adjusted Present Value (APV)
APV = NPV(全股權) + 債務稅盾 - 發行成本 稅盾 = TC × D
核心概念
APV 的邏輯：
1. 先計算項目作為全股權公司的價值
2. 再加上債務帶來的好處（稅盾）
3. 減去發行新債券的成本

為什麼要分開計算？因為債務的稅盾效果很重要，分開顯示能看清楚。
四大融資效應
  • 稅盾（Tax Shield）：利息可以抵稅，相當於免費的補助
  • 發行成本（Flotation Costs）：發行新債需要手續費，1-3% 的成本
  • 困境成本：債務太多，公司破產風險高
  • 其他補貼：政府優惠融資等
稅盾詳解
稅盾是什麼？
假設公司年利息 = $100，稅率 = 30%
利息可以從營業收益中扣除
節省的稅 = $100 × 30% = $30
如果這個債務永遠存在，稅盾現值 = TC × D

舉例：公司借 $1,000，稅率 30%
稅盾價值 = 30% × $1,000 = $300
相當於政府白送 $300 給你！
實際案例：Rapid Cedars
背景：樹木公司考慮是否用債務融資
• 項目初始投資：$100M
• 永續年現金流：$15M
• 無風險資本成本：R0 = 10%
• 計劃借錢：$50M
• 稅率：30%

計算：
全股權 NPV = $15M / 10% - $100M = $50M
稅盾 = 30% × $50M = $15M
APV = $50M + $15M = $65M

含義：因為利用了債務稅盾，項目更值錢了！
流向股東現金流法（FTE）
Flow to Equity (FTE) Method
FTE = ∑ 流向股東的現金流 / RS RS = R0 + (D/E)×(1-TC)×(R0-RD)
核心邏輯
FTE 直接計算股東能拿到多少：
1. 計算項目的杠杆現金流（扣掉利息）
2. 用股東要求的回報率 RS 來貼現
3. 減掉股東的初始投資

優點：直接看到股東拿到的現金，很直觀。
缺點：計算複雜，公式多。
杠杆股權成本 RS 的含義：
R0 = 基礎風險（項目本身的風險）
(D/E)×(R0-RD) = 因為借錢多而增加的額外風險溢價
借錢越多，風險越大，RS 越高
加權平均資本成本法（WACC）
WACC Method for Project Valuation
NPV = ∑ [未杠杆現金流 / (1+WACC)^t] - 初始投資
最簡單的方法
WACC 法的步驟：
1. 計算項目的年現金流（不考慮債務）
2. 用公司的 WACC 來貼現
3. 算出 NPV

為什麼最常用？
• 步驟最少
• 最直觀
• 實務中 80%+ 的公司用這個方法
三種方法對比
特性 APV FTE WACC
現金流 未杠杆 杠杆 未杠杆
折現率 R0 RS WACC
複雜度 高 中 低 ⭐
實務應用 少見 中等 最常用
貝塔的去槓桿化與重槓桿化
Unleveraging and Relevering Beta
去槓桿化：βAsset = βEquity / [1 + (1-TC)×D/E] 重槓桿化：βEquity,新 = βAsset × [1 + (1-TC)×D/E]
實際應用場景
問題：新公司沒有歷史數據，怎麼算貝塔？

解決方案：用行業可比公司！
1. 找 3-5 個競爭對手
2. 獲取他們的股權貝塔
3. 去槓桿化：除掉他們的債務影響
4. 重槓桿化：加上新公司的債務影響
5. 計算新公司的 RE 和 WACC

為什麼要這樣做？不同公司債務比不同，直接用別人的貝塔會不準確。
J. Lowes 膠合劑項目案例
背景：新公司要進入膠合劑行業

Step 1: 行業數據
三個競爭對手（全股權融資）的貝塔：1.2, 1.3, 1.4
平均貝塔 = 1.3

Step 2: 新公司計劃
目標 D/V = 50%（D/E = 1.0）
稅率 = 34%

Step 3: 重槓桿化
βEquity = 1.3 × [1 + 0.66 × 1.0] = 2.158

Step 4: 計算 RE
已知：RF = 5%，市場溢價 = 9%
RE = 5% + 2.158 × 9% = 24.44%

Step 5: 計算 WACC
假設 RD = 5%
WACC = 50% × 24.44% + 50% × 5% × 0.66 = 13.87%

Step 6: 評估項目
初始投資：$100M
永續年現金流：$30M
NPV = $30M / 13.87% - $100M = $116.3M ✓ 接受

第19章：股利與其他分配

本章核心：公司應該向股東分配多少現金？是用股利還是回購？理論上無關，實際中有很多因素。

股利政策無關性（MM 定理）
Dividend Irrelevance Theory (Modigliani-Miller)
核心論點
在完美市場中，股利政策對公司價值無影響！

無論你每年分多少股利，還是都不分，只要公司的投資決策不變，公司價值就不變。

為什麼？因為投資者可以自己調整現金流。
自製股利例子
場景：投資者想每年拿 $1,000 現金

情況 A：公司分 $1,000 股利
→ 投資者直接拿 $1,000

情況 B：公司分 $1,500 股利
→ 投資者拿 $1,500，再把多的 $500 投回公司（或其他投資）
→ 結果等於只拿 $1,000 的現金

情況 C：公司不分股利
→ 投資者賣掉股票來獲得 $1,000
→ 結果也是拿到 $1,000 的現金

結論：投資者通過自己的買賣和投資，可以創造任何他想要的現金流。
所以公司的股利政策對他沒有影響！
MM 定理的前提條件
  • 完美市場（沒有稅、交易成本、資訊不對稱）
  • 公司的投資和融資決策不變
  • 公司不會改變槓桿水平
股利 vs 股票回購
Dividend Payment vs Share Repurchase
完美市場中的等價性
在完美市場中，公司有 $100M 現金要分配：

方案 A：分股利
• 股東拿現金
• 股價下跌（股息已支付）

方案 B：回購股票
• 股東卡片數量減少
• 股價上升（EPS 提升）

結果：股東最終獲得的價值相同！
I&T 公司案例
背景：過量現金 $30M（$3/股）
• 當前股價：$30
• 預期 EPS（支付後）：$4.50
• P/E 比：6

方案 A：分股利 $3/股
→ 股東拿 $3 現金
→ 股價變成：6 × $4.50 = $27
→ 股東總值：$27 + $3 = $30

方案 B：回購股票
→ 回購股數：$30M / $30 = 100 萬股
→ 新 EPS：$45M / (1000-100) = $5.00
→ 新股價：6 × $5 = $30
→ 股東總值：$30

結論：完全相同！
實際中，為什麼公司偏好回購？
  • 灵活性：回購可隨時停止，股利難以削減
  • EPS 遊戲：回購減少股數，EPS 上升（看起來更好看）
  • 稅務優勢：回購的資本利得稅通常低於股利所得稅
  • 估值機會：股票被低估時回購最有利
  • 抵消稀釋：員工期權會稀釋股權，回購可以對沖
稅收對股利政策的影響
Tax Effects on Dividend Policy
稅率差異
股利所得稅：15-35%（視所得稅級距）
資本利得稅（回購）：15-20%

含義：回購通常更稅務友善，尤其是對高收入股東。

例子：
投資者手中 $1,000
• 方案 A：分股利 → 繳稅 30% = $300 稅
• 方案 B：回購增值 → 繳稅 20% = $200 稅
回購省 $100 稅！
稅務最優政策
  • 低股利 + 高回購：延遲納稅，充分利用複利
  • 但也有限制：需要現金充足，無法幫助不想出售股票的股東
  • 政策信號：高派息常被認為是穩定、成熟的信號
股利平滑模型
Dividend Smoothing Model
ΔDiv = s × (t × EPS_current - Div_previous) 其中： - t = 目標派息率（如 30%） - s = 調整速度（0-1 之間） - Div_current - Div_previous = 調整額
企業的真實行為
理論：EPS 上升 20%，股利也立即上升 20%
現實：企業緩慢調整股利，需要幾年才能達到目標

原因：
1. 不確定增長是否永久（保守）
2. 避免因經濟下滑而被迫削減股利（損害信譽）
3. 維持融資靈活性
CGI 公司案例
CGI 的股利政策：目標派息率 30%，調整系數 s = 0.5

Year 1：
• EPS = $10
• 目標股利 = 30% × $10 = $3
• 實際股利 = $3

Year 2：
• EPS 跳升到 $20
• 目標股利 = 30% × $20 = $6
• 實際股利 = $3 + 0.5 × ($6-$3) = $4.50
• 只調整了一半！

Year 3（假設 EPS 維持 $20）：
• 目標股利 = $6
• 實際股利 = $4.50 + 0.5 × ($6-$4.50) = $5.25
• 繼續逐步調整

需要多年才能達到 $6 的目標！
客戶效應（Clientele Effect）
Dividend Clientele Effect
不同投資者的偏好
高稅率投資者：
• 偏好零派息股票（避免被課稅）
• 購買科技成長股

低稅率投資者（退休人士）：
• 偏好高派息股票（需要現金）
• 購買公用事業、銀行股

稅免機構（大學基金、養老基金）：
• 對派息沒有稅收考慮
• 購買平衡型股票

結果：市場自動分割，每家公司找到自己的投資者群體。
政策含義
  • 公司改變派息政策會趕走現有股東，吸引新股東
  • 但總體價值不變（市場完全調整）
  • 一旦客戶群穩定，改變政策收益有限
股利的信號作用
Dividend Signaling
市場反應
歷史觀察：
• 宣布增加股利 → 股價上升 📈
• 宣布減少股利 → 股價下跌 📉

為什麼？
管理層對公司前景有內部資訊。

• 增加股利 = 信號：相信未來現金流充足、增長穩定
• 減少股利 = 信號：預期未來困難、現金緊張

股市解讀這些信號，因此股價反應。
警惕過度解讀
  • 真實含義：管理層認為未來現金流充足
  • 不代表：一定要增加短期股利
  • 更優先：投資 NPV > 0 的項目永遠優於分配股利
明智的派息政策框架
Prudent Dividend Policy Framework
五項核心原則
  • 優先投資：不要為增加股利而放棄 NPV > 0 的項目
  • 現金充足：等到有充足自由現金流再開始派息
  • 目標派息率：設定長期派息率，並逐步調整
  • 自我保險：派息水平要夠低，避免未來融資困境
  • 靈活分配：用回購處理臨時性現金流
實踐建議
公式：自由現金流 = 營業現金流 - 資本支出 - 營運資本增加

決策：
1. 計算長期自由現金流
2. 設定派息率（通常 20-50%）
3. 逐步調整股利達到目標
4. 臨時性現金流用回購
5. 定期檢視和調整
股票股利和股票分割
Stock Dividends and Stock Splits
兩個概念
股票股利（Stock Dividend）：
發放額外股票代替現金
例：10% 股票股利 → 持有 100 股變成 110 股
會計處理：從保留收益轉向資本

股票分割（Stock Split）：
改變每股面值和數量（本質上是大額股票股利）
例：2:1 分割 → 1000 股 @ $66/股 變成 2000 股 @ $33/股

完美市場中：價值不變！
100 股 @ $100 = 200 股 @ $50（總價值相同）
為什麼還要進行分割？
  • 官方理由：把股價恢復到「理想交易範圍」（$20-80）
  • 實際益處：吸引小額投資者、改善流動性、心理效應
  • 學術共識：實際經濟價值有限，更多是心理效應
